
# OpenShift CI/CD Pipeline Project

## Project Name
OpenShift Pipeline Automation using Tekton and GitHub Actions

## Project Description
This project demonstrates Continuous Integration and Continuous Deployment (CI/CD) using GitHub Actions and OpenShift Tekton Pipelines.

## Technologies Used
- GitHub
- GitHub Actions
- OpenShift
- Tekton Pipelines
- Python
- Flake8
- Nose Unit Testing

## Pipeline Tasks
1. Cleanup
2. Git Clone
3. Code Linting using Flake8
4. Unit Testing using Nose
5. Build application using Buildah
6. Deploy application using OpenShift Client

## Objective
To automate application testing, building, and deployment using CI/CD pipeline tools.
